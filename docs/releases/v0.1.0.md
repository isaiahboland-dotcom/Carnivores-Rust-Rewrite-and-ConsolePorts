# v0.1.0

The first tagged source release of Carnivores Classic's Rust rewrite and port tools.
This milestone establishes a versioned baseline for future fixes. It contains no
game or mod assets: bring your own supported game files and follow the
[README](../../README.md) to build and run.

## Highlights

- Linux PC gameplay, layered mods and standalone combinations, saved instances
  and recipes, Ice Age support, and conversion from supported owned Android APKs.
- 3DS cooker and homebrew tools, Wii U demo tooling, and an experimental OpenXR frontend.
- Archive size/path/type checks, bounded input handling, and staged publication
  that preserves an existing generated install on failure. Extract RAR/7z files
  separately before importing their folders.
- Launcher import, rebuild, save, verification, pinning and balance workers use
  one job handle. Running work and unconsumed results cannot be replaced by a new
  action. Presentation modules keep `app.rs` below 800 lines.

## Validation and limits

Local Linux workspace tests passed: **309 passed, 2 ignored, 0 failed** across
43 suites, including 45 launcher tests. Ignored tests were not run.

The release gate covers workspace formatting, Clippy and automated tests, portable
core/VFS checks, host cooker tests, release PC/launcher/cooker builds, and portable
Wii U C tests. GitHub workflows also check Windows builds/tests and cross-compile
the shared format crate for 3DS. These checks use synthetic fixtures and do not
establish gameplay compatibility for every asset pack.

Linux PC is the primary playable baseline. The 3DS port has earlier hardware
testing, but this release does not claim a fresh hardware pass. Windows native
gameplay remains experimental despite CI build/test coverage. Wii U remains a
demo; newer survival, trophy/save, pause/exit and modded-install paths need hardware
validation. PC VR lacks weapons and still needs resource-lifetime review and
runtime diagnostics. A dedicated PS5/PS VR2 port is not implemented.

See [security hardening and remaining limits](../SECURITY-HARDENING.md),
