# v0.4.3

A launcher release on top of [v0.4.0](v0.4.0.md). Versions 0.4.1 and 0.4.2 were
skipped; nothing was released under them.

## Highlights

- **Instances first:** the launcher opens on a grid of instance boxes sized to the
  window. Each shows its base game, number of add-ons, a yellow count of missing items
  and the time played (or "Unplayed"), with **Play**, **Build** and **Options**.
- **Build** asks for the platform (Windows, 3DS or Wii U) and shows only that builder.
  The 3DS and Wii U sections are no longer hidden behind a setting.
- **Options** (or a right click): Edit, Clone, Fix missing, Export, Play in VR, Delete.
  **Import recipe** on the home screen brings in a shared recipe.
- **Edit** shows Base game, Add-ons and Balance pages with Save, Save and exit, Discard
  changes and Cancel. A standalone game can be the base game.
- **Fix missing** finds an instance's base game and downloads in the mod and add-on
  folders set in Settings.
- **Launch protection:** each instance keeps its own game folder, and Play and the
  builds stop when it doesn't match the base game's hashes in the recipe (unless **Use
  this game anyway** is ticked for another version of the same game). This fixes
  instances playing the wrong game after the old Game tab was changed, and the
  "Original" menu showing that game's menus in every instance.

Removed: the Game, Add-ons, Play and console tabs, Settings' engine options
export/import, and dropping archives onto the launcher.

## Validation and limits

Local Linux checks on the release revision: formatting and Clippy (warnings denied)
clean; locked all-feature workspace tests **396 passed, 11 ignored, 0 failed** across 43
suites; host cooker tests 3 passed; release builds of `c2-pc`, the launchers and
`c2-cook`; the 3DS-target `c2-formats` build; 7 portable Wii U C tests. All three
lockfiles resolve with `--locked`. The GitHub CI and Windows workflows must pass on the
pushed revision before the tag is published.

The new launcher screens are covered by headless tests (every screen renders; the box
buttons and right click take clicks; boxes stay inside the scrolled page; an instance
never takes the old Game tab's folder). They have had only a short interactive run by
the owner on Linux PC; the Steam Deck layout and Windows launcher are not yet
re-checked. Instances saved before this release that kept no game of their own need
their base game chosen once (Edit, Base game) or found with Fix missing.
