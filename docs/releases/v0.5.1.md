# v0.5.1

Standalone instances keep their own animals; lights in observer mode

## Fixed

- **Standalone instances took the Game tab's overlays.** An instance on a standalone
  base (Carnivores Triassic, for example) could take the overlays set on the old Game
  tab, which are Carnivores 2 releases such as the Modder's Edition. Their `_RES.TXT`
  replaced the standalone's animals: the hunt menu showed Carnivores 2 names over the
  standalone's pictures, Carnivores 2 animals spawned in the hunt, and the editor's
  Advanced page (predation, spawn rules, base game parts) and Balance page listed
  Carnivores 2's animals. Editing the instance saved the overlays into it.
- Only Carnivores 2 instances take the Game tab's overlays now. Instances that already
  have them saved drop them on Play, Edit and Build; an overlay added to an instance on
  purpose is kept.

  If an affected instance still shows Carnivores 2's animals (for example, after the Game
  tab's overlays were changed), open **Edit > Base game** and remove the entry under
  **Unpinned overlays**.

- **Night vision and the flashlight in observer mode** (PC, Android). Picked on the gear
  page in a dynamic-time hunt, they were left out of observer hunts, so their keys,
  the pad's stick click and the phone's light buttons did nothing. They now work as in
  a normal hunt.

## Validation and limits

- A launcher test covers a standalone instance with the Game tab on the same folder, a
  saved copy of the Game tab's overlays, an overlay of its own, and a Carnivores 2
  instance combining standalones. It fails on v0.5.0 and passes on v0.5.1.
- Checked on Linux PC against the Carnivores Triassic data: with the Modder's Edition
  overlay the instance read Carnivores 2's nine animals; without it, Triassic's own.
- A unit test covers which lights a hunt takes from the gear page. The observer-mode
  lights have not been hand-checked in a hunt yet.
- Neither fix has been re-checked on the Steam Deck, where both were reported.
