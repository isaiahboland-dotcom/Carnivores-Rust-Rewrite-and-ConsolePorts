# v0.7.1

Fixes for 0.7.0. Everything in [v0.7.0](v0.7.0.md) still applies; the full
list is in [CHANGELOG.md](../../CHANGELOG.md).

## Fixes

- **Wii U hunt setup.** 0.7.0 added the bounded fleeing setting to the hunt
  choice the Rust game reads, but not to the C header the Wii U menu writes,
  so the two disagreed on its layout. Both sides now match, and a check on
  each side guards it.
- **3DS title page.** Without Survival the buttons now close up instead of
  leaving a gap. They are listed in order (Play, Survival, Trophies,
  Settings, Quit, Profile), centred, and taps use the same layout as the
  drawing. The DHC OS title no longer has a "MAIN MENU" header cut by the
  first button.
- **3DS hunt options.** The bounded fleeing toggle's label fits its box.

## Known issues

- 3DS: on a pack without a trophy room, the Trophies entry is dimmed and does
  nothing when tapped.
- Hardware checks for these fixes, and the 0.7.0 ones, are still pending
  (3DS and Wii U).

## Downloads

The desktop bundles (`linux.tar`, `windows.zip`) are attached by the
Release bundles workflow. They contain no game data: you need your own
Carnivores 2 install.

## Validation status

- Automated: PC workspace Clippy (warnings denied) and locked tests; the
  stable host cooker tests, including the new 3DS title layout tests; the
  portable Wii U C tests; `cargo 3ds build --release -p c2-3ds` with no
  warnings. The Linux bundle was built locally from the release revision.
- Pending: the 3DS title page and hunt options label on hardware; the Wii U
  hunt setup on Cemu and hardware; clean-machine checks of both desktop
  bundles (see [the release checklist](../RELEASING.md)).

Recipe edits and personal recipe copies are excluded from this release commit.
