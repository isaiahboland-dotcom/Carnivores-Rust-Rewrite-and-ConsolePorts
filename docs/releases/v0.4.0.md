# v0.4.0

A gameplay and launcher release on top of [v0.1.0](v0.1.0.md). skipping 0.2 and 0.3

## Highlights

- **Hunt options:** an opt-in day/night cycle with night vision and flashlight
  equipment, multi ammo (lethal rounds and tranquilizer darts in one weapon), and an
  advanced observer mode with flying and a time stop. These are on PC and Wii U.
- **Survival** was rewritten on a points budget. Only Classic and Modded remain. The
  mobile Survive files, dialect waves, Hardcore/Custom and the ring spawn are gone.
  I might revisit those at a later date, but to keep it more in-line with our goals
  I will be sticking to this decision.
- **PC map:** zoom centred on the cursor, panning, and aligned radar and teleport selection.
- **Android-based games** always use the phone's menus, with touch buttons for the
  night equipment.
- **Launcher:** Pick parts for standalone games (including an instance's base game),
  balance editing per instance, menu choices, Instances cards, and Steam Deck interface
  sizing and full screen. A standalone that is on is no longer loaded as an add-on as well.
- **3DS cooker:** a pack is written when only some areas exceed the memory budget.
  The over-budget areas are named and the console refuses those hunts.
- **Hardening:** tighter `_RES.TXT`, PKM, mobile ELF and cooked-pack bounds. CI actions
  are pinned, Dependabot is configured, and there is a daily all-feature test run.
- **Steamdeck** a steamdeck install script added to make installation/updating easier
  on the steamdeck

## Validation and limits

Local Linux workspace checks passed before the version bump. Formatting and Clippy
(warnings denied) were clean. Locked all-feature tests: **391 passed, 11 ignored,
0 failed** across 43 suites. Host cooker tests: 3 passed. Ignored tests were not run.
After the bump, a locked workspace check and the 3DS and Wii U lockfiles resolved
unchanged. The GitHub CI and Windows workflows must pass on the pushed revision
before the tag is published. These checks use synthetic fixtures. They do not show
that every asset pack plays correctly.

Linux PC is still the primary playable baseline. Windows native gameplay
remains experimental
